# 여의도 차량 분산 배치와 보충

프로젝트의 Python 의존성과 SUMO를 설치한 환경에서 실행한다.

```sh
python -m inference.fixed_population_panel
```

Windows에서는 프로젝트 루트의 `여의도_분산교통_실행.cmd`로도 실행할 수 있다.

기존 uniform 교통의 600초 저장 상태에서 도로 위 일반 차량 수를 센 뒤, 도로 길이와 차로 수에 따라 도로망 전체에 초기 배치한다. 기준 대수는 심야 462대·주간 3,338대·출근 4,417대다. 승용차 통행이 가능하고 안전 간격과 다음 도로 연결을 확보한 차로만 배치 대상으로 사용한다.

일반 차량은 연결된 도로 두 구간을 운행하고 도착한다. 부족해진 대수는 배정량보다 비어 있는 차로에 보충한다. 자율주행 차량의 전체 출발·도착 경로는 유지하며, 기존 일반 차량을 강제로 옮기거나 삭제하지 않는다. 삽입은 SUMO의 안전 검사를 따른다.

목표 대수에는 도로 위·삽입 대기·순간이동 복귀 중인 일반 차량이 포함된다. 따라서 매 순간 도로 위 대수가 목표와 같지는 않다. 주행 중 시간대를 바꾸면 새 목표에 맞춰 보충하며, 목표가 낮아지면 도착에 따라 자연 감소한다. 새 주행을 시작하거나 주행하지 않을 때 시간대를 바꾸면 초기 배치를 다시 불러온다.

이 모드는 차량 대수와 공간 분포를 제어하는 실험 환경이며, 실제 통근 OD나 시간당 유입량을 재현하지 않는다. 배경 차량이 자주 교체되므로 누적 생성·도착 대수를 실측 통행량과 직접 비교하면 안 된다.

초기 상태·SUMO 설정·입력 해시·검증 결과·화면 파일은 `env/yeouido/fixed_population/`에 자동 생성한다. 이 폴더는 Git에 포함하지 않는다.

```sh
python -m unittest discover -s tests -p test_fixed_population.py
python -m inference.fixed_population_panel --validate --seconds 180
python -m inference.fixed_population_panel --smoke --delay 0
```

검증은 세 시간대의 목표 대수 초과 여부, 도착 후 보충, 충돌을 확인한다. GUI smoke 검사는 시간대 전환과 주행 시작을 확인한다. 운전자는 기존 선생님 정책이며, 학습 모델의 성능 평가와는 구분한다.
